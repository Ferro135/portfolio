# ALUNERI 3.0.0 — Signature Portfolio

## Redesign completo do portfólio público

Esta versão muda completamente a direção visual do site público para um layout mais premium, editorial e autoral.

### O que mudou
- Hero totalmente refeito com composição mais forte, números, prova de valor e case em destaque.
- Nova linguagem visual do portfólio com aparência de estúdio digital premium.
- Seção de projetos reorganizada para valorizar desafio, solução e identidade de cada case.
- Nova seção de estúdio/capacidades com narrativa visual mais elegante.
- Processo refeito com cards mais sofisticados.
- FAQ e CTA final atualizados para combinar com a nova proposta.
- Header e footer refinados.
- Páginas públicas internas receberam polimento visual geral (hero, grids, cards, CTA e áreas de contato).

### Técnico
- Nenhuma funcionalidade removida.
- Nenhuma migration do Supabase.
- Admin preservado.
- Foco principal desta versão: layout e direção visual do site público.
