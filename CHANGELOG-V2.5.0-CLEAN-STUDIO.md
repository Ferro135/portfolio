# ALUNERI 2.5.0 — Clean Studio

## Objetivo
Reorganizar o site e o painel administrativo reduzindo ruído visual,
quantidade de caixas e informação concorrendo ao mesmo tempo.

## Site público
- Hero completamente refeito.
- Removido o mockup decorativo falso do Hero.
- Zentra passa a aparecer como projeto real em destaque.
- Navegação reduzida para Projetos, Serviços, Sobre e Contato.
- Barra de especialidades simplificada.
- Projetos passam a aparecer em linhas grandes, uma por vez.
- Serviços viraram uma lista editorial em vez de uma parede de cards.
- Processo virou uma timeline simples.
- Seção Sobre foi simplificada para mensagem + 3 princípios.
- Tecnologias reorganizadas por grupos.
- FAQ reorganizado.
- Contato final reduzido e mais claro.
- Menos glow, menos bordas e menos elementos decorativos.

## Admin
- Shell administrativo simplificado.
- Branding reduzido para ALUNERI + Admin.
- Topbar limpa, sem atalhos visuais desnecessários.
- Dashboard reorganizado em:
  1. Cabeçalho e estado do banco
  2. 4 KPIs
  3. Pipeline + pendências
  4. Leads recentes + agenda
- Inner pages recebem superfícies mais simples e consistentes.
- Sidebar e navegação ficaram menores e mais legíveis.

## Técnico
- Nenhuma funcionalidade removida.
- Nenhuma migration do Supabase.
- `public/aluneri-version.json` atualizado para 2.5.0.
